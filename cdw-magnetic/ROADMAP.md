# Дорожная карта: NJL₃ в магнитном поле

Дата: 2026-11-07. Верхний план задачи. Детальные планы этапов — [ветка A](notes/00-plan.md) (неоднородный TDP) и [ветка B](notes/stability/00-plan.md) (устойчивость). Постановки — [tasks.md](tasks.md), вопросы и решения — [questions.md](questions.md), журнал результатов — [findings.md](findings.md).

**Цель.** Повторить для задачи с постоянным перпендикулярным полем $B$ ту же цепочку, что в работе без поля на $\mathbb R^2\times S^1$ (параметр $L$):

**формулы → быстрые и проверенные алгоритмы → однородная диаграмма → неоднородная диаграмма → анализ устойчивости → расчётная веб-лаборатория.**

Аналогия с задачей $(\mu,L)$: дискретность дают уровни Ландау $\varepsilon_n=\sqrt{M^2+2n|eB|}$ вместо мод компактификации; фазы различаются числом заполненных уровней; роль пиков $\mu_n=2\pi n/L$ играют пороги $\mu^2=2n|eB|$.

## Код

Пакет в `cdw-magnetic/`. Предлагаемая структура:

```
cdw-magnetic/
├── magcdw/            # пакет
│   ├── hom/           # Ф1, А1: однородный TDP, G(M), корни, линии переходов
│   ├── inh/           # Ф2, А2–А3: модель Раби, вакуум, быстрый движок, карты
│   ├── stab/          # Ф3, А4: пропагатор, D(q), карты устойчивости
│   └── common/        # единицы, тепловые веса, общие утилиты
├── tests/             # pytest: формулы против независимых расчётов
├── code/              # исследовательские скрипты и отчёты (как notebooks/)
└── web/               # лаборатория (этап 5)
```

Нынешние модули из `code/` переносятся в пакет по мере стабилизации; скрипты и отчёты остаются в `code/`.
